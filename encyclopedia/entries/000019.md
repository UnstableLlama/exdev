## Problem

The metadata interface returns uppercase EXL3 while the sidecar serializes lowercase exl3; the commit message requests consistent capitalization.

## Reasoning

Changes Linear.quant_format_id to return lowercase. However, the parent quant_config.py checks `qformat == "EXL3"`, and this commit does not update that consumer. As a result, the branch that adds quant_format and bits_per_weight will no longer run for these linears. This is an observable contract mismatch, not harmless text formatting.

## Impact

Attempts to normalize the interface identifier but temporarily makes generated tensor_storage omit its EXL3-specific format and bitrate fields. The storage inventory itself is still constructed.
