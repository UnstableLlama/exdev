## Problem

The caller joins work_dir into the output filename, then save_tensor joins work_dir again. With a relative work directory this produces `work/work/qtensors/...`.

## Reasoning

Passes the helper a path relative to the working directory: `qtensors/{module.key}.safetensors`. The helper owns the work_dir prefix. Although the message says “double absolute path,” the parent implementation and a Python path check show that an absolute second argument replaces the first prefix; the demonstrable duplication is with a relative work_dir.

## Impact

Makes quantized-module output paths consistent with the save helper’s contract and the directory created by prepare_env.
