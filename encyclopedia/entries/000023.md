## Problem

Conversion calls free_mem repeatedly around quantization, metric calculation and module transitions.

## Reasoning

Comments out five explicit free_mem calls. The parent helper performs Python garbage collection and empties the CUDA allocator cache, so the removed work includes both operations rather than only Python GC. Tensor reference deletions and module unloads remain in place.

## Impact

Trades repeated explicit cleanup for less cleanup overhead during conversion. Possible throughput gains and memory-pressure effects need measurement; this does not disable every allocator or garbage-collection mechanism globally.
