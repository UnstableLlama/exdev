## Problem

The parent scale search quantizes sampled tiles repeatedly over a coarse grid and then a finer grid: 12 plus 16 evaluations. An unused outlier-ratio search also remains.

## Reasoning

Replaces the active grid search with golden-section search over [0.1, 1.9], terminating when the interval width is at most 0.01. One interior function value is reused each iteration. The code explicitly assumes a unimodal quantization-error function; this is an assumption, not a demonstrated property of discrete trellis quantization. The searched interval is broader than the old [0.25, 1.075] coarse interval, so this is not merely an equivalent implementation. Deletes the unused outlier routine and old progress constants.

## Impact

Reduces repeated sampled-tile evaluations under the search assumption and changes possible selected scales. The packed tensor schema stays the same. The proxy_err naming problem identified in entry 000012 is not addressed by this diff. The extracted `phi` token is the golden ratio variable, not evidence of a Phi model addition.
