## Problem

MANIFEST.in includes Hadamard data but has no explicit rule for shipping the extension source tree required by JIT compilation.

## Reasoning

Adds a recursive include for exllamav3/exllamav3_ext while retaining Hadamard data. The parent ext.py builds source lists and calls cpp_extension.load, so an installed package needs those source files when the precompiled extension is unavailable.

## Impact

Addresses packaging completeness for JIT use. The reviewed type is bugfix rather than the miner’s default feature tag; the actual sdist/wheel file inventory was not built here.
