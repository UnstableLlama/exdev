## Problem

The extension source list is built with absolute paths. The commit message reports that setup rejects this form and identifies issue #2.

## Reasoning

Replaces `os.path.abspath` with `os.path.relpath(..., start=os.path.dirname(__file__))`, making each discovered C/C++/CUDA source path relative to the setup-script directory. The os.walk traversal and extension filters are unchanged. This targets packaging-path representation, not compiler source selection.

## Impact

Changes how extension sources are passed into package building. The specific environment and full error report cannot be reconstructed from the eligible issue content.
