## Must fix before any canonical use (not blocking ancestor retrieval)

1. One consequence is unstated: the helpers now modify the tensor held in `H_data["H"]` itself, where the old code produced new tensors and rebound a local name. If finalization fails partway (for example in the Cholesky step), the stored Hessian is left partly transformed and `finalized` is still false, so a retry would transform it again. The old code already modified it in place for the averaging and sign steps, so this is a matter of degree, but a canonical entry about an in-place change should say what is and is not restartable.
2. The removed line carried a to-do ("in-place had kernels, to save some memory here"). The draft says the helpers "are mutating Python helpers, not allocation-free custom kernels", which is the right observation; tie it to that to-do so the reader sees the change answers it only partly.
