## Reviewer-only notes (never to a teacher)

- **Three differences from the Qwen3 MoE builder that the entry does not state** (it read no ancestor entry):
  the model does not set `calibration_all_experts`, so calibration uses ordinary top-2 routing; the MLP's output
  dtype is half where Qwen3 MoE asks for float; and there are no query or key norms. None is a defect. Because
  the flag is not set, the all-expert fused-shape condition recorded at 139 cannot be triggered through this
  model's own conversion path.
- **155 was the preparation for this.** With eight experts the router's width would have been padded to 128
  before 155, and the 120 padded columns would have entered softmax and top-2. The entry at 155 could not know
  that; this entry does not look back. Worth a sentence in a canonical version of either.
- Watch for a later commit that turns all-expert calibration on for Mixtral or changes the output dtype.
