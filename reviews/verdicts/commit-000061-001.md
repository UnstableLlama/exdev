## Must fix before any canonical use (not blocking ancestor retrieval)

Both "glm" and "GLM" return nothing in the parent tree, which means no GLM architecture is registered at this commit: the example gains a prompt mode for a model family the library cannot yet load. 3. No separator follows the system prompt or a completed answer before the next role marker, unlike the Phi template's `<|end|>`. The draft notes this as a design fact; a canonical entry should mark its correctness as unestablished.
