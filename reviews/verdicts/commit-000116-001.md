## Reviewer-only notes (never to a teacher)

- **CPU inputs.** The kernel is launched unconditionally, so a `Linear` with a qmap capturing on the CPU would hand host
  pointers to CUDA. Not reachable at this commit: conversion loads on the CPU only modules with `prefer_cpu`, which is
  `Embedding` alone, and it has no qmap. Worth remembering if a later commit captures on the CPU.
- **32-bit index.** `blockIdx.x * BLOCK_SIZE` is evaluated in 32-bit unsigned arithmetic before widening, so it wraps
  for a single tensor of 2^32 or more elements. Calibration inputs are far smaller. The entry lists integer overflow
  as untested, which is the right level of claim.
- The added block reuses the comment "Swap captured H to system RAM" above the warning loop. Cosmetic.
