## Must fix before any canonical use (not blocking ancestor retrieval)

1. **Issue 8.** The entry must report it: the failure, the author's stated diagnosis, and the timing, with the link labelled as inference on the basis given above.
2. **What happens to the padded logits.** The draft says outputs are wider and compatibility "was not established". Two consumers are in the tree and settle part of it:
   - `exllamav3/generator/sampler/custom.py:258` sets `logits[..., tokenizer.actual_vocab_size:]` to negative infinity when a tokenizer is passed, so the sampler already discards columns beyond the real vocabulary. The padded columns are zero weight and zero or absent bias, so without that mask they would be logits of exactly 0.
   - `exllamav3/generator/generator.py:74` computes `padded_vocab_size` as the vocabulary rounded up to a multiple of **32**, and `job.py:718` sizes `held_logits` with it. The head now pads to a multiple of **128**. For a vocabulary that is a multiple of 32 but not of 128, the two widths differ where before they agreed. I did not trace what `SeqTensor.append` does with the mismatch, so this is a source-level inconsistency on the `return_logits` path, not a demonstrated failure.
3. **The fused-branch bias.** After `pad_out`, a bias has length `out_features`; it is then sliced with `frange`, whose bounds index the fused tensor, not this layer. For a first sub-layer (`frange` starting at 0) the slice cuts the padding back off, leaving a bias shorter than the padded weight; for later sub-layers the slice falls partly or wholly outside. The branch only matters when a tensor exists at `key + ".bias"` for a fused layer, which the draft and I did not establish for any model. It belongs in the entry as a suspected finding, not only as a limit.
4. **Padding a non-head projection changes the residual width.** For a model whose hidden or intermediate size is not a multiple of 128, `o_proj`, `down`, `up` and `gate` now emit wider tensors than the stream they add into. The draft says padding applies to every Linear; it should state this consequence as source reasoning, unexecuted.
5. The Source Notes paragraph about the commit 19 discriminator mismatch is true and irrelevant here; it is an artefact of the inherited-defect guidance firing on any file with history.
