## Standing rule from here (extends the 113 precedent)

A teacher run that completes its tool calls but whose final annotation is refused by the validator for a citation
error (an identifier that does not exist, or an existing identifier of a kind the rule does not accept) may be
followed by **one** fresh unassisted attempt on the same packet without a separate request, provided the next
request says so and the failed run is kept. A second consecutive failure at the same position needs a request.
